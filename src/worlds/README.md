# Миры

Мир — это тема, в которой играют по общим правилам: ресурсы и их значки,
научные школы, цивилизации с Великими сооружениями и карты. Правила
(3 эпохи по 6 ходов, торговля с соседями, войны, подсчёт очков) у всех миров
одни и те же.

Каждый мир — папка с файлом `world.json` и картинками рядом. Имя папки —
идентификатор мира. Новая папка подхватывается сама: достаточно её добавить
и пересобрать сайт.

```
src/worlds/
  ancient/
    world.json
    wood.svg      картинки, на которые ссылается world.json (необязательно)
  space/
    world.json
```

Сейчас есть два мира: «Древний мир» (`ancient`, по умолчанию) и «Космос»
(`space`; те же карты и баланс, другие названия и значки). Хост выбирает мир
в лобби; справка вне комнаты позволяет посмотреть любой мир.

## world.json

```jsonc
{
  "name": "Древний мир",               // название в лобби и справке
  "description": "…",                  // одна строка под названием
  "order": 1,                          // место в списке миров; первый мир — по умолчанию
  "bots": ["Хаммурапи", "…"],          // имена ботов (к ним добавится «Бот»)
  "resources": [
    // kind: "raw" — сырьё, "goods" — товары
    {"id": "wood", "name": "дерево", "icon": "🪵", "kind": "raw", "img": "wood.svg"}
  ],
  "schools": [
    {"id": "astronomy", "name": "Астрономия", "icon": "🔭"}
  ],
  "civs": [ … ],                       // цивилизации, формат как в ancient
  "cards": [ … ]                       // карты, формат как в ancient
}
```

- `icon` — текстовый значок (эмодзи). Если указан `img`, вместо значка
  показывается картинка из папки мира, а `icon` остаётся подписью.
- `img` можно указать у ресурсов, школ, цивилизаций и карт. Форматы: svg,
  png, webp, jpg, gif, avif.
- Ресурсы и школы в картах и цивилизациях указываются по `id`.
- Школа `any` зарезервирована: эффект `{"kind": "science", "school": "any"}`
  даёт любую школу на выбор.

## Требования

Тест `npm test` проверяет каждый мир:

- не меньше 7 цивилизаций, у каждого сооружения 3 стадии;
- в каждой эпохе ровно 7 карт на игрока при любом числе игроков от 3 до 7 (в эпохе III —
  без учёта династий), династий — не меньше чем игроков + 2;
- цепочки ведут к картам следующих эпох;
- все ресурсы и школы существуют, все картинки лежат в папке.

Баланс мира можно прогнать ботами: `WORLD=<id> npm run sim`.
